# Limitations and integrity statement

Phase 1 is a scaffold. No model is downloaded or loaded; no text normalization, tokenization, language identification, transliteration, POS/NER, ambiguity resolution, translation, or evaluation is implemented. `/ready` reports this explicitly. No confidence values or linguistic predictions are fabricated.

The sample records are illustrative and unvalidated. Model support for Romanized code-mixed Telugu, model licenses, compute needs, and causal traceability remain to be tested. Neural translation quality cannot be inferred from a dictionary or rule fallback.
