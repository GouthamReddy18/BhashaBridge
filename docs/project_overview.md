# Project overview

LipiPrism (formerly BhashaBridge 2.0) is a research prototype for Telugu–English code-mixed input, including Romanized Telugu. The framework conceptualizes code-mixed analysis through an optical prism: one utterance examined across multiple linguistic dimensions. The system preserves source text and exposes each processing stage so users can inspect normalization, language labels, transliteration, ambiguity, translation, and uncertainty.

Phase 1 provides only the repository foundation, health/readiness API, minimal frontend, and illustrative data. It does not analyze or translate sentences.
