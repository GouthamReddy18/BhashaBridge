# Problem statement

Code-mixed Telugu?English text can use native Telugu script, variable Latin spellings, English vocabulary embedded in Telugu grammar, and informal or incomplete forms. A pipeline must distinguish transliteration from translation, protect named entities and technical terms, use context for genuine ambiguity, and disclose uncertainty.

The examples in this repository are illustrative prompts, not validated linguistic annotations or benchmark examples. Before quantitative evaluation, establish a documented annotation guide and independently review references.
